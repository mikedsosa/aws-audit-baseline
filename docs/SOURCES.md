# Sources

Draft. The pages below were fetched on 8 November 2026, except the rows that say they were read on 10 November 2026. They are not a substitute for a later fact-check. Claims in the other docs that are not tied to a row here should be treated as design notes, not as quotations.

| Claim used in this draft | Page |
| --- | --- |
| CloudTrail log delivery needs `s3:GetBucketAcl` and `s3:PutObject` for `cloudtrail.amazonaws.com`, with `aws:SourceArn` and `bucket-owner-full-control`. A dedicated bucket is recommended. A misconfigured trail is retried for 30 days and those attempts are charged; delete the trail to stop the charges. | https://docs.aws.amazon.com/awscloudtrail/latest/userguide/create-s3-bucket-policy-for-cloudtrail.html |
| Trail KMS use needs `kms:GenerateDataKey*` with `aws:SourceArn` and the CloudTrail encryption context, `kms:DescribeKey` with `aws:SourceArn`, and `kms:Decrypt` for the service. The published decrypt statement has no source condition. `aws:SourceAccount` is supported and not the recommended key. An S3 Bucket Key on an existing bucket requires `kms:Decrypt` when creating an SSE-KMS trail. | https://docs.aws.amazon.com/awscloudtrail/latest/userguide/create-kms-key-policy-for-cloudtrail.html |
| Four Block Public Access settings. They are independent. Account and organization settings exist and the most restrictive combination applies. The page recommends all four at the account and on each bucket, and warns that a bucket policy can be changed to disable a bucket-level block. | https://docs.aws.amazon.com/AmazonS3/latest/userguide/access-control-block-public-access.html |
| Bucket-owner-enforced ownership disables ACLs and still accepts `bucket-owner-full-control`. SSE-S3 is the default encryption. HTTPS via `aws:SecureTransport` is recommended. Versioning and Object Lock are recommended, including Object Lock for CloudTrail logs. New buckets and ACLs defaults, the April 2026 SSE-C note, and the shared global namespace warning are on this page. VPC endpoints are recommended there and were not used in this boundary. | https://docs.aws.amazon.com/AmazonS3/latest/userguide/security-best-practices.html |
| Example deny of `s3:*` when `aws:SecureTransport` is false, on the bucket ARN and the object ARN, principal `*`. | https://docs.aws.amazon.com/AmazonS3/latest/userguide/example-bucket-policies.html |
| Log file validation uses SHA-256 and signed digest files. Enabling it delivers digests; it does not validate them. Digest files can show deletion or a gap. MFA Delete is mentioned as an additional control and is not used here. | https://docs.aws.amazon.com/awscloudtrail/latest/userguide/cloudtrail-log-file-validation-intro.html |
| If SSE-KMS and log file validation are both used, and the bucket policy allows only SSE-KMS encrypted files, trail creation fails unless the policy also allows AES256. The documented condition is `StringNotEquals` of `s3:x-amz-server-side-encryption` to `["aws:kms", "AES256"]`. That example assumes CloudTrail sends one of those two values. Read 10 November 2026. | https://docs.aws.amazon.com/awscloudtrail/latest/userguide/best-practices-security.html |
| A negated operator such as `StringNotEquals` is true when the condition key is absent. A `StringNotEquals` deny on `s3:x-amz-server-side-encryption` therefore denies a request that omits the header, before default encryption applies. `StringNotEqualsIfExists` on a `Deny` also denies the request when the key is absent. Read 10 November 2026. | https://docs.aws.amazon.com/IAM/latest/UserGuide/reference_policies_elements_condition_operators.html |
| `aws:PrincipalServiceName` is present only for a service principal. It is absent for an IAM caller. The published S3 example uses `StringNotEqualsIfExists` on that key and names `cloudtrail.amazonaws.com`. Read 10 November 2026. | https://docs.aws.amazon.com/IAM/latest/UserGuide/reference_policies_condition-keys.html |
| An S3 bucket policy that denies `PutObject` with `StringNotEquals` on `s3:x-amz-server-side-encryption` requires the request to include that header. The page says this can block writers that do not send the header. Read 10 November 2026. | https://docs.aws.amazon.com/AmazonS3/latest/userguide/UsingServerSideEncryption.html |
| When Security Hub is enabled, AWS says billing for included capabilities is consolidated under Security Hub. Capabilities not included in those plans, including remaining GuardDuty capabilities, keep their own service billing. No prices are copied here. Read 10 November 2026. | https://aws.amazon.com/security-hub/pricing/ |
| A bucket-policy `Deny` does not stop S3 Lifecycle expiration. Lifecycle actions do not use the `DeleteObject` operation; they use internal S3 endpoints. To stop a lifecycle rule, edit, delete, or disable the rule. Read 10 November 2026. | https://docs.aws.amazon.com/AmazonS3/latest/userguide/troubleshoot-lifecycle.html |
| Trails log management events by default, not data or Insights events. Multi-Region trails record all enabled Regions into one bucket and are modified in the home Region. Five trails per Region; a multi-Region trail counts as one per Region. Organization trails are a different configuration. Global service events for multi-Region trails require `IncludeGlobalServiceEvents`. Event history is described as the past 90 days of management events. | https://docs.aws.amazon.com/awscloudtrail/latest/userguide/cloudtrail-concepts.html |
| CreateTrail defaults: log file validation false, multi-Region false, organization trail false. `KmsKeyId` accepts an alias name, an alias ARN, a key ARN, or a key id. `KmsKeyNotFoundException` includes the case where the bucket and key are in different Regions. `IncludeGlobalServiceEvents` delivers global events for a multi-Region trail or for a trail in the partition leader Region. | https://docs.aws.amazon.com/awscloudtrail/latest/APIReference/API_CreateTrail.html |
| One management-event copy to S3 is described as free, with limits. Further prices used in the runbook: additional management copies $2.00 / 100,000; data events $0.10 / 100,000; network activity events $0.10 / 100,000; Insights management $0.35 / 100,000 per type; CloudWatch Logs delivery $0.25 / GB. S3 storage is extra. 90-day event history is described as no additional charge. | https://aws.amazon.com/cloudtrail/pricing/ |
| Customer managed keys are $1/month. The first and second rotations each add $1/month, capped at the second rotation. 20,000 requests/month free, then the S3 example uses $0.03 / 10,000. Keys pending deletion are not charged; canceling deletion resumes charges. | https://aws.amazon.com/kms/pricing/ |
| Automatic rotation default period is 365 days when unset. Automatic rotation applies to symmetric encryption keys with AWS KMS key material. Rotation does not re-encrypt existing data. | https://docs.aws.amazon.com/kms/latest/developerguide/rotate-keys.html |
| Deleting a KMS key is irreversible. Symmetric ciphertext cannot be decrypted by a new key after deletion. Waiting period is 7–30 days, default 30, and can run up to 24 hours longer. The key cannot be used while pending deletion. | https://docs.aws.amazon.com/kms/latest/developerguide/deleting-keys.html |
| S3 Bucket Keys can reduce KMS request costs by up to 99 percent, in AWS's words. Bucket keys use the bucket ARN as encryption context. Not supported for DSSE-KMS. | https://docs.aws.amazon.com/AmazonS3/latest/userguide/bucket-key.html |
| `terraform show -json` plan shape: `format_version`, `resource_changes`, `after`, `after_unknown`, configuration expressions, and output changes. | https://developer.hashicorp.com/terraform/internals/json-format |

| Key arguments used here, including `rotation_period_in_days` 90–2560 and `deletion_window_in_days` 7–30. The provider example delegates `kms:*` to the account root. | https://registry.terraform.io/providers/hashicorp/aws/latest/docs/resources/kms_key |
